# Rules

## Living Documentation
Whenever you modify the codebase, alter the architecture, or adjust the mathematical/algorithmic logic in this project, you MUST proactively update the English `README.md` to reflect these changes. Ensure the documentation always stays synchronized with the current state of the code. Do not use Hebrew for the README; it must remain in English to efficiently pass elaborated descriptive information.

## Target Git Repository
Always commit and push code changes in this workspace to the target remote repository: `https://github.com/yubranvalde-byte/finance-app`. Ensure remote URL is configured accordingly.
